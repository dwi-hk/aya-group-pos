# Kasir / Penjualan - Mart Layout v2.15.0

Perubahan hanya ditujukan ke tampilan route **Kasir / Penjualan**.

- Daftar menu berubah menjadi baris tunggal vertikal seperti kasir minimarket.
- Nama menu dipaksa satu baris (ellipsis bila terlalu panjang).
- Area menu memiliki scroll vertikal sendiri.
- Barcode/kode scanner diperbesar dan diberi panel hasil scan terakhir.
- Item hasil scan langsung disorot pada nota berjalan.
- Total transaksi ditampilkan besar dan sticky di bagian atas panel kanan.
- Panel katalog dan nota tetap berdampingan pada desktop/tablet landscape.
- Semua field, keterangan, tombol transaksi, delivery, diskon, pembayaran, hold, dan cetak tetap dipertahankan.
